# Atajos y búsqueda

Todo lo importante está a una tecla de distancia.

## Atajos de navegación

| Acción | Atajo |
| --- | --- |
| Abrir una carpeta | `Ctrl + O` |
| Mostrar u ocultar la barra lateral | `Ctrl + B` |
| Ir atrás | `Alt + ←` |
| Ir adelante | `Alt + →` |
| Recargar el documento | `F5` |
| Cerrar menús o búsqueda | `Esc` |

## Atajos de lectura

| Acción | Atajo |
| --- | --- |
| Buscar en el documento | `Ctrl + F` |
| Siguiente resultado | `Enter` |
| Resultado anterior | `Mayús + Enter` |
| Aumentar el tamaño de letra | `Ctrl + +` |
| Reducir el tamaño de letra | `Ctrl + −` |
| Tamaño original | `Ctrl + 0` |

## Buscar en todos los documentos

La pestaña **Buscar** del panel lateral recorre el contenido de todos los archivos
Markdown de la carpeta. No importa si la palabra lleva tilde: `cancion` encuentra
`canción`.

1. Abre la pestaña **Buscar**.
2. Escribe al menos dos caracteres.
3. Pulsa `Enter`.
4. Haz clic en un resultado para abrirlo y saltar a la primera coincidencia.

> La búsqueda se detiene después de revisar una cantidad razonable de archivos para
> que la aplicación siga respondiendo. Si tu carpeta es enorme, verás un aviso de
> **búsqueda parcial**.

## Buscar dentro de un documento

`Ctrl + F` abre la barra de búsqueda sobre el documento. Los resultados se resaltan
mientras escribes y puedes recorrerlos sin perder el hilo.

- La búsqueda no distingue mayúsculas de minúsculas.
- Tampoco distingue tildes.
- Al cerrar la barra, los resaltados desaparecen.

## Temas y tipografía

Puedes cambiar entre tema claro, oscuro o el tema del sistema desde el menú
principal. El tamaño de letra se ajusta con `Ctrl + +`, `Ctrl + −` o desde el mismo
menú.

Las preferencias se guardan automáticamente: la próxima vez que abras Lector MD
encontrarás el mismo tema, tamaño de letra y ancho de la barra lateral.
