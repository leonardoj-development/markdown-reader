# Checklist de viaje

Una lista práctica para no olvidar lo importante. Sirve también como ejemplo de una
carpeta con varios niveles.

## Documentos

- [ ] Pasaporte o documento de identidad
- [ ] Reservas del hotel
- [ ] Pasajes
- [ ] Seguro de viaje

## Equipaje

| Categoría | Elementos |
| --- | --- |
| Ropa | Abrigo, camisetas, calcetines |
| Tecnología | Cargador, adaptador, audífonos |
| Aseo | Cepillo de dientes, protector solar |
| Lectura | Un libro y esta carpeta de notas |

## Antes de salir

1. Revisar el clima del destino.
2. Descargar los mapas sin conexión.
3. Avisar a alguien del itinerario.
4. Cargar el teléfono y la computadora.

> **Truco:** deja la maleta abierta un día antes. Lo que agregues de último minuto
> suele ser lo que realmente necesitas.
