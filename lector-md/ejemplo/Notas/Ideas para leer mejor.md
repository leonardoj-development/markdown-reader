# Ideas para leer mejor

Leer muchos documentos seguidos puede convertirse en una carrera. Estas son algunas
ideas para que la biblioteca siga siendo un lugar tranquilo.

> La atención es un músculo. También se cansa.

## Una rutina posible

1. Abre la carpeta al empezar el día.
2. Elige un solo documento.
3. Lee de principio a fin sin saltar entre pestañas.
4. Anota una idea antes de pasar al siguiente.

## Antes de empezar

- [x] Silenciar las notificaciones
- [x] Elegir una taza de algo caliente
- [ ] Cerrar las pestañas que no vas a usar
- [ ] Decidir cuánto tiempo vas a leer

## Tres señales de que toca una pausa

1. Lees la misma frase por tercera vez.
2. Buscas una excusa para abrir otra pestaña.
3. Ya no recuerdas por qué empezaste este documento.

No es un fracaso: es información. Descansa, camina o mira por la ventana.

## Volver a empezar

Si te pierdes, siempre puedes volver a la [bienvenida](../Bienvenido.md), abrir la
[guía de Markdown](<../Guía de Markdown.md>) o usar `Alt + ←` para retroceder en el
historial.
